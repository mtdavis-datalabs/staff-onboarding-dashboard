### staff-onboarding-dashboard
# **Staff Onboarding Tracker &amp; Dashboard in Excel** 

## **Overview:**

_This Excel dashboard tracks task progress across the staff onboarding process, giving managers a quick visualisation of who's responsible for what onboarding tasks and how much they've progressed_


## **Key Features:** 
- **Summary Stats** - Live counts of tasks by status (Not Started, In Progress, Complete, Overdue), plus total task count, overall % complete, and tasks flagged "at risk."
- **Task Status Breakdown** - Doughnut chart visualising the proportion of tasks in each status category at a glance.
- **Owner Completion Stats** - Tracks completion rate for each internal employee responsible for onboarding tasks (Line Manager, IT, HR), and shows how many of their assigned tasks have been completed versus outstanding. This highlights which role or team might be causing delays in a new hire's onboarding.
- **% Tasks Complete by Owner** — A bar chart comparing completion percentage across task owners, making bottlenecks easy to spot.
- **Staff Onboarding Timeline** — A Gantt-style chart mapping each onboarding task (e.g., setting up system logins, scheduling inductions, issuing employee ID) against a day-number timeline, showing planned duration and sequencing.


## **Skills Demonstrated:** 
- Dashboard design
- Data aggregation with formulas (COUNTIF/SUMIF-style summary stats)
- Chart selection for different data stories (donut for status proportions, bar for owner comparison, Gantt for timeline/sequencing)
- Structuring a spreadsheet for stakeholder readability


## **Tools Used:**
- Microsoft Excel — conditional formatting, COUNTIF, charts, dashboard layout
