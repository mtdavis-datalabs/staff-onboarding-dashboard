# staff-onboarding-dashboard
_Staff Onboarding Tracker &amp; Dashboard in Excel_
This Excel dashboard tracks task progress across the staff onboarding process, giving managers a quick visualisation of who's responsible for what onboarding tasks and how mich they've progressed.
_Key features_: 
* _Summary Stats_ - Live counts of tasks by status (Not Started, In Progress, Complete, Overdue), plus total task count, overall % complete, and tasks flagged "at risk."
* _Task Status Breakdown_ - Doughnut chart visualising the proportion of tasks in each status category at a glance.
* _Owner Completion Stats_ - Tracks completion rate for each internal employee responsible for onboarding tasks (Line Manager, IT, HR), and shows how many of their assigned tasks have been completed versus outstanding. This highlights which role or team might be causing delays in a new hire's onboarding.
* _% Tasks Complete by Owner_ — A bar chart comparing completion percentage across task owners, making bottlenecks easy to spot.
* _Staff Onboarding Timeline_ — A Gantt-style chart mapping each onboarding task (e.g., setting up system logins, scheduling inductions, issuing employee ID) against a day-number timeline, showing planned duration and sequencing.
_Skills demonstrated_: dashboard design, data aggregation with formulas (COUNTIF/SUMIF-style summary stats), chart selection for different data stories (donut for status proportions, bar for owner comparison, Gantt for timeline/sequencing), and structuring a spreadsheet for stakeholder readability.
_Note on data_: Figures shown have been fictionlised for portfolio purposes; the structure reflects a real onboarding tracking workflow.
